자동봇 커미션

기본 안내

  • 마스토돈 서버에서 사용하는 자동봇 커미션입니다. 구글 시트와 연동하여 사용합니다.
  • 타입 내에 기재되지 않은 기능도 오마카세 자동봇을 통해 대부분 구현해 드립니다.
  • 개발 중 기능이 늘어나는 등 요청사항이 생기면 추가금이나 마감일이 변경될 수 있습니다.
  • 자동봇 유지보수는 기간 제한 없이, 작업 완료 후에 전달드리는 오픈채팅에서 진행합니다.
  • 서버 설치도 함께 필요하시다면 서버 설치 커미션 페이지를 확인해주세요.

가동 기간에 따른 금액

  • 가동비는 1주 5천원이에요. (테스트 기간 제외) 커뮤 운영 주수만큼 올려 주세요.
  • 12개월 이상 장기 서버용은 주당 비용 대신 초기 세팅비 1만원만 받으니, 2주(1만원)로 맞춰 주세요.
  • 지난 신청자분들의 자동봇도 지금까지 꾸준히 업데이트해 드리고 있습니다.

커스텀 명령어 업그레이드란?

  • 커스텀 명령어: 운영진이 시트에 적은 명령어를 입력하면, 짝지은 문구 중 하나가 랜덤으로 나와요. (예: [허기] 입력 시 아래 허기 문구 3개 중 하나)
  • 업그레이드하면 아래 {중괄호}처럼 유저 이름, 은/는 맞춤, 다이스를 문구에 넣을 수 있어요.
명령어예시 문구 (업그레이드 시 사용 가능)
패션오늘의 패션 점수는 {1d100}점입니다.
능력치능력치는 민첩: {3d6} / 힘: {3d10+5} / 운: {1d100} 입니다.
허기{시전자}{은는} 배가 고픕니다.
허기배가 고픈 나머지 {시전자}{이가} 옆에 있던 친구를 잡아먹었습니다.
허기여러분, {시전자}{을를} 굶기지 마세요.
즐거운 발견당신은 {랜덤: 숟가락, 젓가락, 밥그릇, 깨진 유리}{을를} 찾아냈습니다!

봇 타입 상세

* 기본 계열 타입은 하나만 고를 수 있어요.

  • •구글 스프레드시트 연동
  • •[nDm] [랜덤/옵션, 옵션, 옵션...]
  • •[운세] 명령어와 기본 운세 문구 제공
  • •[가위바위보] [YN] 등 커스텀 명령어 기능 기본 제공
  • •기본 타입에 포함된 모든 기능 +@
  • •구글 시트로 캐릭터, 재화, 인벤토리 관리 (운영진 수동 편집 지원)
  • •[소지금 추가/금액/캐릭터명] [소지금 차감/금액/캐릭터명] (운영진 명령어)
  • •[상점] 아이템 목록 출력
  • •[구매/아이템명] 아이템 구매 시 재화 차감
  • •[가방] 인벤토리, 재화 확인
  • •기본&상점 타입에 포함된 모든 기능 +@
  • •구글 시트로 캐릭터 스탯 관리 (운영진 수동 편집 지원)
  • •[OO 변경/수치/캐릭터명] (운영진 명령어 / 예: 체력 변경)

  • •기본 계열 타입과 함께 신청할 수 있어요.
  • •[장소 목록] [진입/장소명] [조사/포인트명]
  • •장소 목록과 각 장소에서 조사할 수 있는 포인트 관리
  • •캐릭터 소지품 및 스탯과 연동 (특정 이벤트 발생 시 아이템 획득 / 체력 -5 등)
  • •D100 롤언더(기능치 이하 성공) 판정을 쓰는 TRPG용 자동봇
  • •봇과 연동된 플레이어, 커스텀, 랜덤표 구글 시트 제공 (편집 가능, 표 내용은 직접 입력)

  • •판정 기능만 드려요. 룰북 내용(광기 목록 등)은 직접 입력해 주세요.
